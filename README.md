# AestheticBiz

Patient Revenue Platform demo for [aestheticbiz.site](https://www.aestheticbiz.site) — Next.js port of the Lumina mockup, branded for CRM Solutions outreach.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

| Route | Purpose |
|-------|---------|
| `/` | Full medspa homepage |
| `/book` | Custom booking wizard |
| `/gift-cards` | Gift card commerce demo |
| `/rewards` | AestheticBiz Points |
| `/features` | Platform pitch |
| `/audit` | Sample commercial audit |

Discovery CTAs point to `crmsolutions.app/book-discovery-call?source=aestheticbiz*`.

## Stack

Next.js 15 · React 19 · TypeScript · Lumina visual system (navy / gold clinical luxury).
